# Diplom_Bibl — Система автоматизации библиотеки

WPF-приложение для автоматизации работы библиотеки, разработанное в рамках дипломного проекта.

## 📋 Описание

Приложение предназначено для управления библиотечным фондом, читателями, выдачей и возвратом книг, а также формирования отчетов.

## 🔧 Технологии

- **Платформа**: .NET Framework 4.7.2
- **Язык**: C#
- **UI Framework**: WPF (Windows Presentation Foundation)
- **IDE**: Visual Studio 2022
- **Тесты**: xUnit / NUnit (Diplom_Bibl.Tests)

## 🚀 Основные возможности

- **Авторизация пользователей** — разграничение прав доступа
- **Управление книжным фондом**:
  - Добавление, редактирование, удаление книг
  - Массовый импорт книг из Excel
  - Учет движения фонда
  - Списание книг (акт списания)
- **Работа с читателями**:
  - Регистрация читателей
  - Импорт данных читателей из Excel
  - Генерация читательских билетов (PDF)
- **Выдача и возврат книг**
- **Справочники**:
  - Авторы, жанры, издательства
  - Должности, пользователи
  - Статусы книг, специальности
- **Отчетность** — формирование различных отчетов
- **Информационное обслуживание**

## 🛠️ Установка и запуск

### Требования

- Windows 10/11
- .NET Framework 4.7.2 или выше
- Visual Studio 2019/2022 (для разработки)

### Запуск готового приложения

1. Скачайте релизную версию
2. Запустите `Diplom_Bibl.exe`

### Сборка из исходного кода

```bash
# Клонируйте репозиторий
git clone <repository-url>
cd Diplom_Bibl

# Откройте решение в Visual Studio
Diplom_Bibl.sln

# Соберите проект (Build → Build Solution)
# Или через командную строку:
msbuild Diplom_Bibl.sln /p:Configuration=Release
```

## 🧪 Тестирование

Проект включает модульные тесты в проекте `Diplom_Bibl.Tests`.

```bash
# Запуск тестов через Visual Studio Test Explorer
# Или через консоль:
vstest.console.exe Diplom_Bibl.Tests\bin\Release\net472\Diplom_Bibl.Tests.dll
```
